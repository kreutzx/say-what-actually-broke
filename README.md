## The line

> Your document didn't fail to save. We never saved it — the button was decorative for 6 months, and 41,000 of you pressed it daily.

## Why this line

An error message that finally says what actually broke: nothing was ever saved. The save button was decorative for 6 months, and 41,000 users pressed it daily — two concrete specifics (6 months, 41,000 people) that turn a vague failure notice into a confession.

## Running it
